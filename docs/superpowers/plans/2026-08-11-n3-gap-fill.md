# N3 词量补缺 + 复合动词试点 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** N3 现有 1284 词（动词300/名词850/形容词55/副词68/拟声词11），官方大纲粗估约 3750 词，缺口约 2466。本次目标：①在名词/形容词/副词/拟声词四个已有类别里补充新词；②调研 N3 是否值得建立复合动词类别——**根据 N4 阶段调研的结论，N2/N3 是复合动词开始有"真实独立词条"（而不只是能产性语法模式）的分界点**，所以 N3 大概率能收到有实质内容的复合动词词表，但仍需先调研确认规模再决定，不能想当然。

**Architecture:** 复用 `2026-08-10-n5-gap-fill.md`/`2026-08-10-n4-gap-fill.md` 已验证的方法论：WebSearch 多源采集 + jisho.org/Bunpro 双源等级核实（冲突保守排除）+ 全站零重叠去重 + subagent 生成 + `npm run validate` 不改。**心理预期**：前两轮经验（N5 缺口193实际补5词，N4 缺口912实际补28词）反复证明公开可验证的真实词量远低于官方估计，本轮缺口2466不代表真能补上千词，以实际能验证的为准，但由于N3体量本身就大（大纲词汇多），预期这轮的绝对产出会比N4/N5高。

**Tech Stack:** 纯前端静态站点、Node.js `--test`、WebSearch/WebFetch、Claude subagent。

## Global Constraints

- Schema不变，不改 `scripts/validate-cards.js`
- 拟声词 `word` 必须等于 `kana`
- 复合动词（如Task 0判定N3有实质内容）沿用动词schema：`type`+可选`transitivity`，助记法优先用真实词素分解（参考 `generate-batch-n2-compound-verb.md`）
- 例句难度必须是 N3 等级（可用被动/使役/基础敬语/复合助词，不能超N2词汇）
- **全站零重叠**：新词不能和 N1-N5 任何现有文件的 `word` 重复
- 等级核实用 jisho.org + Bunpro 双源交叉确认，冲突保守排除；注意 Bunpro 页面可能出现"A#"教材deck编码或推广横幅，不是真实等级标注（N4阶段踩过这个坑，本轮要延续那次学到的严格核实提示词）
- 跨文件兼类词标准延续之前几轮
- 目标词量不预设强制指标，宁缺毋滥
