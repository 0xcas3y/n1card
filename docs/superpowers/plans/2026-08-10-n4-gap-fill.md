# N4 词量补缺 + 复合动词试点 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** N4 现有 588 词（动词150/名词351/形容词46/副词40/拟声词1），官方大纲粗估约 1500 词，缺口约 912。本次目标：①在名词/形容词/副词/拟声词四个已有类别里补充新词，尽量逼近官方量级（不强行凑数）；②调研 N4 是否值得建立复合动词类别（复合动词语法点通常从 N4 开始出现，比 N5 更有可能有实质内容，但仍需先调研再决定，不能想当然）。

**Architecture:** 复用 `2026-08-10-n5-gap-fill.md` 已验证的方法论：WebSearch + jisho.org/Bunpro 双源等级核实、全站零重叠去重、subagent 生成、`npm run validate` 不改。**重要提醒（继承 N5 阶段的教训）**：官方"约1500"只是粗估，前几轮经验（N5实际补缺仅5词、N3首轮986/3450、N4首轮438/1350）反复证明公开可验证的真实词量远低于官方估计，本轮也要有心理预期——缺口912不代表真的能补908+词，以实际能验证的为准。

**Tech Stack:** 纯前端静态站点、Node.js `--test`、WebSearch/WebFetch、Claude subagent。

## Global Constraints

- Schema不变，不改 `scripts/validate-cards.js`
- 拟声词 `word` 必须等于 `kana`
- 复合动词（如果Task 0判定N4有实质内容）沿用动词schema：`type`+可选`transitivity`
- 例句难度必须是 N4 等级
- **全站零重叠**：新词不能和 N1-N5 任何现有文件的 `word` 重复（不只是 N4 自己的文件）
- 等级核实用 jisho.org + Bunpro 双源交叉确认，冲突则保守排除（延续 N5 阶段确立的策略）
- 跨文件兼类词标准延续之前几轮
- 目标词量不预设强制指标，宁缺毋滥
