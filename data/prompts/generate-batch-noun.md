# N1/N2 名词 Card Batch Generation Prompt

改编自 `generate-batch-adverb.md`（副词版），用于生成名词批次。和副词版本的关键差异：部分名词可以直接加「する」变成动词（如 打ち合わせする、勘違いする），生成时如果输入词表标了（する），要在 `meanings` 或例句里体现这个用法；不标的就是纯名词，不要强行造「〜する」例句。

## Input

一份 JLPT 指定级别的常见名词列表（一行一个，调用方直接给出），可能带（する）标记表示可作サ变动词。

## Output

JSON 对象 `{ "version": 1, "cards": [...] }`，每张卡片符合下面 schema：

- `id`（number）：调用方指定起始偏移量后的 1-based 序号
- `word`（string）：名词书写形式（有汉字写汉字，纯假名名词就等于 `kana`）
- `kana`（string）：平假名读音，仅 U+3040-309F + 30FC
- `accent`（string|null）：不确定就填 `null`
- 不写 `type`/`transitivity` 字段（名词不适用）
- `meanings`（string[]）：1-4 条简洁中文释义。如果这个词可加「する」，在释义末尾追加一条"（＋する：…）"说明サ变动词义，或者直接在例句里体现，不强制两种都写
- `mnemonic`（string）：**短语叙事体助记法**（沿用动词/形容词/副词版本的三关标准：音准 + 短语连贯 + 含义钩子），词块必须是真实可查证的日语词，拼接短语必须是真实存在的日语说法，不能是凑巧对上音的编造词。如果实在凑不出干净的多词块短语，可以退回到"直接用这个词本身的真实汉字读音做锚点，交叉引用另一个用同一汉字的真实词汇"这种更朴素但站得住脚的写法，不要为了凑短语编造不存在的词。复合名词（比如 手掛かり、前触れ 这类由两个已知词拼成的词）可以直接用词素分解说明含义，不必强求语音游戏。
- `examples`：**恰好 2** 个对象，每个 `{ jp, cn }`。如果词表标了（する），至少一个例句用「〜する」形式；没标的就用名词本身的自然搭配（当主语/宾语/定语），不要生造别扭的谓语用法。

## Quality checklist

- [ ] 助记法过三关：音准 + 短语连贯 + 含义钩子，或朴素的真实汉字读音锚点，或复合词词素分解
- [ ] `kana` 字段纯平假名（跑 `scripts/validate-cards.js` 校验）
- [ ] 不写 `type`/`transitivity` 字段
- [ ] 标了（する）的词，例句体现サ变动词用法
- [ ] 例句是母语者会说的自然搭配
