# N2 动词 Card Batch Generation Prompt（补缺专用）

改编自 `data/prompts/generate-batch.md`（N1 动词版，本项目最初的动词生成 prompt），schema 和助记法风格完全复用，只是把词表等级换成 N2。这是本项目第一份专门的 N2 **普通动词**（非复合动词）批量生成 prompt——N2 首轮的 200 个动词是用户直接提供的成品词表，没有走生成 prompt 流程；本次补缺是首次需要从零生成 N2 动词卡片。

## Input

一份 N2 等级动词列表（一行一个，辞书形，汉字/假名混写）。

## Output

JSON 对象 `{ "version": 1, "cards": [...] }`，每张卡片：

- `id`（number）：调用方指定起始偏移量后的 1-based 序号
- `word`（string）：动词辞书形（如给出词条是纯假名但有常见汉字写法，优先用汉字写法，保持跟站内其他动词卡片一致的书写习惯）
- `kana`（string）：平假名读音，仅 U+3040-309F + 30FC，不含汉字/片假名
- `accent`（string|null）：Tokyo accent 数字字符串，不确定就填 `null`，不要猜
- `type`（string）：`"五段"` | `"一段"` | `"サ变"` | `"カ变"`
- `transitivity`（string|null）：`"自"` | `"他"` | `"自他"`，不确定就填 `null`，不要猜
- `meanings`（string[]）：1-4 条简洁中文释义，5-15字
- `mnemonic`（string）：**音节拼短语式助记法**（跟 N1 动词版一样，不是复合动词版的词素分解式，因为这些是普通动词不是两个动词的拼接）：把假名读音拆成 2-4 个已知日语词块，拼接后等于目标读音，再组成一个有意义的日语迷你短语，用中文记忆钩子收尾。

  **格式：**
  ```
  chunk(kana) + chunk(kana) + chunk(kana) ⇒ <日语迷你短语>（<中文记忆钩子>）
  ```

  **三条硬标准：**
  1. **音节保真** — 词块读音拼接 = 目标假名读音（允许一处轻微凑读，须标注ほぼ）
  2. **短语连贯** — 词块拼成的是真实或接近真实的日语短语/句子
  3. **意义钩子** — 短语的画面/故事要呼应动词本身的含义，括号里的中文要把短语和词义连起来

  **参考范例（来自 generate-batch.md）：**
  - `幼い(おさない)` → `お + 酒(さ) + ない ⇒ お酒ない（幼年不能喝酒）`
  - `受け(うけ) + 玉(たま) + 割る(わる) ⇒ 受けた玉を割る（敬领后连玉都敢砸？要恭听！）`
  - `様(さま) + 酔う(よう) ⇒ 様子が酔う（状态如同醉酒迷失，就是彷徨游荡）`

  **要避免的坏例子：**
  - 只有音节拼接没有短语没有意义钩子
  - 解释汉字结构而不是解释读音
  - 纯音节堆砌，没有真实词块锚点

- `examples`：**恰好 2** 个 `{ jp, cn }`。难度是 N2 等级的自然书面/口语句子，可以用被动/使役/敬语/复合助词/书面语表达；支撑词汇不需要刻意限制在 N2 本级以内，出现常见 N1 词汇也没问题（N2 是仅次于最高级的等级，例句词汇上限本来就很宽松），但不要为了炫技堆砌生僻词，句子要自然。

## Quality checklist

- [ ] `type` 判断依据整个动词的实际活用形（可用「〜ます」测试）
- [ ] `transitivity` 不确定就填 `null`，不要猜
- [ ] 助记法三条硬标准全部满足：音节保真 + 短语连贯 + 意义钩子
- [ ] 中文记忆钩子把短语和词义连起来，不是简单直译
- [ ] `kana` 字段纯平假名
- [ ] 例句是自然的 N2 等级日语，不刻意限制在N2以内的支撑词汇，但也不刻意堆砌生僻词
- [ ] 生成完之后自查 JSON 有效性（`node -e "JSON.parse(...)"`），避免助记法/例句里出现未转义的直引号，用「」代替
